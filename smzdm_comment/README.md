# 什么值得买评论任务修复

本目录供现有 `hex-ci/smzdm_script` 青龙部署使用。将 `library_task.js`、`comment_bot.js`、`comment_client.js` 放入原脚本目录；保留原有 `bot.js`、`env.js`、`sendNotify.js` 和任务入口。

评论使用独立的当前上游客户端参数、Cookie 构造、服务器时间和签名。共享客户端与签到、抽奖、补签配置不随此修复替换。

在青龙环境变量中设置 `SMZDM_COMMENT_AUTO=true`，会为能识别的文章选择匹配文案。目前支持回音壁、键盘、发错货和第六代骁龙8类内容；其他文章可根据已读取的正文生成引用内容的提问；正文不足或无法可靠匹配时停止发布并通知。关闭自动模式后，继续使用 `SMZDM_COMMENT`，含固定话题的文案必须匹配当前任务。指定话题、栏目和文章按任务提供的目标筛选，无法确认的内容要求不会退回普通文章。

任务按真实剩余数量执行，每条提交后必须核对计数增长。指定文章支持页面短 ID，优先处理小目标任务；全站累计活动按平台目标减去已完成数量继续执行，进度和停止原因会写入日志。评论写请求零自动重试，按平台实时目标和已完成数量确定本次发布数量。成功返回ID但未计入会保存记录并停止；真实结果未知的请求禁止重发。已接受但未计入的记录可在明确授权的独立验证中保留历史，使用其他文章和新文案继续，历史提交计数保留，不设置与任务无关的固定每日条数。

达到目标并处于可领取状态才领取该评论任务奖励；以 `is_received=1` 及已领取状态核验，支持平台状态4。有效评论保留。同文章同文案记录摘要防重复，测试锁只由当前持有者释放，异常及SIGTERM执行清理。

客户端及部分原方法来源：[hex-ci/smzdm_script](https://github.com/hex-ci/smzdm_script)，保留其MIT许可证。部署前备份原文件；回退时恢复备份的 `library_task.js`，并保留评论记录、锁及补签状态，不清零预算。
